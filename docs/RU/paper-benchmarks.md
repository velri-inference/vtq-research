# Сквозное сравнение форматов (`VTQ` vs `EXL3` vs `GGUF`)

Все форматы (`VTQ` `.vtq` v2, `EXL3` `mul1` и `GGUF` `imatrix`) квантизованы из одного BF16-чекпоинта на **общей доменно-нейтральной калибровке потока** (`wikitext-2-raw-v1` `train`, `64 × 2048 = 131 072` токена) и замерены end-to-end (включая квантизованные `embed_tokens` и `lm_head`) на трёх непересекающихся выборках (`B = 2000` / `4000` парный бутстрэп):
- **`wikitext2`** — отложенный тест `wikitext-2-raw-v1` `test` (`40` сегментов),
- **`nemotron`** — многоходовые агентные, SWE, математические и reasoning-диалоги (`nem`),
- **`multilingual`** — диалоги на `10` языках (`ru / de / es / fr / it / zh / ja / ko / pt / hi`, `mul`).

Дефолтный солвер апстрима VTQ (**`VTQ-SketchA`**, [`src/build_yaqa_sketch_a.py`](../../src/build_yaqa_sketch_a.py) + [`src/vtq_gptq2d.py`](../../src/vtq_gptq2d.py)) добавляет один переиспользуемый проход открытой мультидоменной калибровки YAQA `Sketch-A` (`256 × 512`, строго непересекающейся с оценочными трейсами), собирая 5-out `G_out` для двустороннего GPTQ-2D и KL-взвешенные `H_in` (смесь `0.50` с `H_stream`), при **нулевых изменениях формата `.vtq` v2, `total_bpw` и декодеров Velri** (флаг `--fast-1d` запускает прежний быстрый 1D-солвер `VTQ (1D)`).

Битрейт `total_bpw` считается напрямую по полному размеру текстовой модели на диске (`total_text_bytes * 8 / total_text_params`). Во всех **3 архитектурах × 4 целевых битрейтах × 3 выборках (`36 из 36` ячеек)** **`VTQ-SketchA`** показывает строго меньший teacher-forced KLD, чем и `EXL3` (`35 / 36` статзначимых побед, `−27%..−34%` на `Llama-3.1-8B`, **`−52%..−57%` на `gemma-4-26B`** при `2.5–4.5 bpw`, `−21%..−35%` на `Qwen3.6-35B`), и `GGUF`, одновременно улучшая старый 1D `VTQ` (**`22 / 36` статзначимых побед, `0 / 36` статзначимых поражений**) и оставаясь в **1.4–2.3× быстрее** `EXL3` на полном пакете из 4 битрейтов (даже с учётом однократного сбора `Sketch-A`). Однорядные графики по KLD (`*_kld.svg` / `.png`) также лежат в [`docs/figures/`](../figures/).

## Полное воспроизведение бенчмарков и графиков

Все графики `SVG/PNG` в `docs/figures/` пересобираются прямо на `main` из `results/paper_*.json` командой `python -m src.plot_paper_benchmarks`. Для полного сквозного перезапуска с нуля по BF16-чекпоинтам — включая версионированные отложенные трейсы (`data/`), `SHA-256` манифест и пошаговую сборку `llama.cpp` / `exllamav3` — переключитесь на ветку [`paper-repro`](https://github.com/velri-inference/vtq-research/tree/paper-repro) (`git checkout paper-repro`). Флаг `--fast-1d` в `src/run_paper_benchmarks.py` отключает YAQA `Sketch-A` для воспроизведения быстрого 1D-бейзлайна.
