# Сквозное сравнение форматов (`VTQ` vs `EXL3` vs `GGUF`)

Все три формата (`VTQ`, `EXL3` `mul1` и `GGUF` `imatrix`) квантизованы из одного BF16-чекпоинта на **строго идентичной нейтральной калибровке** (`wikitext-2-raw-v1` `train`, `64 × 2048 = 131 072` токена) и замерены end-to-end (включая квантизованные `embed_tokens` и `lm_head`) на трёх непересекающихся выборках:
- **`wikitext2`** — отложенный тест `wikitext-2-raw-v1` `test` (`ppl_ref = 7.5537`),
- **`nemotron`** — англоязычные многоходовые диалоги (`ppl_ref = 3.9697`),
- **`multilingual`** — диалоги `ru / zh / de / fr / es` (`ppl_ref = 3.3358`).

Битрейт `total_bpw` считается напрямую по полному размеру текстовой модели на диске (`total_text_bytes * 8 / total_text_params`).
